# Financial Modeling Skill

A Codex skill for building, auditing, and repairing Excel financial models. It covers operating forecasts, three-statement models, DCF and reverse DCF, LBO, M&A, and scenario analysis.

## Install

Download or clone this repository and copy the entire [`financial-modeling`](financial-modeling/) folder into your Codex skills directory. Keep `SKILL.md` and `references/` together. Restart Codex if the skill does not appear.

## Use

Invoke `financial-modeling` and describe the model, the decision it supports, and the Excel environment you plan to use. Start with the [skill instructions](financial-modeling/SKILL.md).
